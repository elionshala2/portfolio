# ⚡ Elion Shala — Personal Portfolio

A modern, responsive portfolio website featuring a dark aesthetic, interactive HTML5 Canvas animations, audio visualizer, and custom certificate modal system. Built with plain HTML, CSS, and modern JavaScript (ES6).

🌐 **Live Demo:** [elionshala2.github.io](https://elionshala2.github.io)

---

## ✨ Features

- **Interactive Canvas Network:** Real-time grid animation with mouse-tracking and audio-reactive boost effects.
- **Background Music Player:** Web Audio API integration with an active frequency visualizer.
- **Certificate Viewer:** Interactive modal system for displaying verified credentials.
- **Asynchronous Contact Form:** AJAX form submission powered by Formspree with instant inline UI feedback.
- **Glitch & Custom Cursor:** Custom dynamic cursor, hover states, and glitch styling effects.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Graphics & Audio:** HTML5 Canvas API, Web Audio API
- **Hosting & Deployment:** GitHub Pages
- **Form Integration:** Formspree API
